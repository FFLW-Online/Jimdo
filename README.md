# FFLW - Jimdo-Bestandskopie

Erste möglichst originalgetreue Übernahme der öffentlich sichtbaren Jimdo-Inhalte.

## Installation
Alle Dateien und den Ordner `assets` in die oberste Ebene des GitHub-Pages-Repositorys hochladen.
